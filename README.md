# A-Lighter-Introduction

一个以 `ACHTUNG / West-Berlin` 告示牌为视觉核心的打火机产品介绍网页。项目通过黑色背景、红色警示线、德文标语和产品广告图，营造出与柏林墙、边界、冷战记忆相关的视觉氛围。

## 项目效果

项目包含两个页面：

- `index.html`：首页入口页面，展示一张仿告示牌风格的 `ACHTUNG` 标签。
- `detail.html`：详情页面，展示打火机产品广告图，并提供中德双语介绍文案。

用户在首页点击告示牌后，会进入详情页。在详情页中可以点击“查看详细信息”展开介绍文字，也可以点击“返回”回到首页。

## 主要功能

- 首页居中展示 `ACHTUNG / Sie verlassen jetzt / West-Berlin` 告示牌。
- 鼠标悬停告示牌时，告示牌会轻微放大并产生红色发光效果。
- 点击首页告示牌后跳转到详情页。
- 详情页展示产品图片 `images/lighter.png`。
- 详情页提供“返回”按钮，可回到首页。
- 详情页提供“查看详细信息 / 收起详细信息”按钮，用于展开或隐藏中德双语产品说明。
- 页面包含基础响应式适配，移动端下会自动缩小主要内容宽度和文字尺寸。

## 文件说明

- `index.html`  
  首页结构，包含告示牌和提示文字。

- `detail.html`  
  详情页结构，包含产品图、返回按钮、详情按钮和中德双语介绍文案。

- `style.css`  
  页面全部视觉样式，包括黑色背景、告示牌样式、产品图样式、按钮样式、详情卡片和移动端适配。

- `script.js`  
  页面交互逻辑，包括首页跳转、详情页返回、详情文案展开和收起。

- `images/lighter.png`  
  打火机产品广告图。

## 使用方式

这个项目是纯静态网页，不需要安装依赖。

直接在浏览器中打开：

```text
index.html
```

也可以使用任意静态服务器运行项目，例如 VS Code 的 Live Server 插件。

## 交互流程

1. 打开 `index.html`。
2. 点击首页告示牌。
3. 页面跳转到 `detail.html`。
4. 在详情页查看产品图。
5. 点击“查看详细信息”展开中德双语说明。
6. 点击“收起详细信息”隐藏说明。
7. 点击“返回”回到首页。

## 设计主题

项目围绕“边界”“记忆”“自由”展开视觉表达。打火机不只是一个产品物件，也被设计成承载历史记忆的媒介：火光象征瞬间、提醒与自由，而 `West-Berlin` 告示牌则强化了冷战与柏林墙的历史语境。
